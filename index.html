My Work

Machine Learning for Historical Legal Text Classification

A computational project finetuning and applying BERT and DistilBERT models to identify and classify Jim Crow laws within a large historical legal corpus of laws passed during the Reconstruction Era (1865 - 1968)

The image to the right is the project poster created for the American Association of Law Libraries (AALL) 2023 Annual Meeting. The poster highlights the methods, tools, and results of the project. Code samples and the full project repository are available on GitHub linked below.

  • Role: Machine Learning and Data Analysis lead
  • Tools:
  • Python
  • Hugging Face Transformers
  • Tensorflow
  • Pandas
  • LoRA
  • Q-LoRA
  • Methods:
  • Transformer classification
  • Sentence Segmentation
  • Batch Training
  • Model Validation
  • Large-scale Text Analysis

Climate Data for Virginia

Data analysis of the temperature changes in the Charlottesville region using DAYMET and NOAA data repositories, and advanced GIS in R to create digestible result visualizations for stakeholders to support policy decisions. Also developed a shiny app and a process for animating multiple years of map polygons.

The image to the right is a sample of the animated map polygons created for this project. The animation shows the changes in temperature over time in the Charlottesville region. The full shiny app, animation code, and repository are available on GitHub linked below.
